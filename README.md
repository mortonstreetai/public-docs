# Morton Street docs

Source of https://docs.mortonstreet.ai, built with [Mintlify](https://mintlify.com).

This repo is published automatically from the Morton Street codebase, where the docs are checked
against the MCP server on every change. Edits made here directly are overwritten; to suggest a
change, open an issue.

```bash
npx mint@latest dev   # preview at http://localhost:3000
```
