---
title: "Cursor"
description: "Add the Morton Street MCP server to Cursor."
---

Add this to `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (one project):

```json
{
  "mcpServers": {
    "mortonstreet": {
      "url": "https://api.mortonstreet.ai/mcp"
    }
  }
}
```

Open **Cursor Settings → MCP**. Morton Street shows as needing login; click it to sign in in your browser.
